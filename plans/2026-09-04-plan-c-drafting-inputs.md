- Anchor ref `1:1-B/2026-05-06`; observable-moves refs `TEAM/2026-05-06`, `1:1-B/2026-07-13`,

- **Messaging drafts (verbatim):**
  1. *"I run engineering on a no-heroes standard: if an outcome depends on one person's

  2. *"Sustainable scale means nobody is load-bearing alone. Every key-person dependency gets
     engineered out; resilience is designed into the org chart, not hoped for."*
  3. *"I'd rather celebrate a boring quarter than a heroic one. Heroics are evidence the
     system failed someone."*
- **Caveat (verbatim):** *"Guillermo never names it in the summaries... **Do not present the
  name as his.**"*
