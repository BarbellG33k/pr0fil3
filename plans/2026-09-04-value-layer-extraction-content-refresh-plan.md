   **Portfolio initiatives** = narrative + metrics. **Framework cards** = mechanism
   definitions. **Case studies** = deep narrative with context/diagnosis/mechanism/
   outcome boundaries.

   their vocabulary enriches existing Manifest / Operating Model Transformation
   artifacts rather than duplicating them.
3. **Canonical phrase list:** any new line used in 2+ artifacts is worded identically
   everywhere (maintained in the placement map, Wave 1).
4. Every new public claim gets an evidence-ledger record **before** publication.
5. Attribution ladder (July 2026 plan §IX) governs verbs: built / architected / led /
   established / sponsored / co-created / coached / contributed / participated. The
   Sep 3 corpus supports "helped shape", "established", "directed attention to" —
   not "delivered" or measured results.
6. Outcome confidence: the entire Sep 3 corpus is `directional`/`attributed`; no
   `verified` outcomes may be derived from it. Planned/directed work is never phrased
   as achieved.
7. Anonymization (AGENTS.md): role terms only in public copy ("the Principal Engineer",
   "the Senior Engineering Manager", "an offshore office"); neutral ref codes
   (`TEAM/2026-05-20`) are allowed; `INTERNAL-provenance.md` never referenced publicly.
